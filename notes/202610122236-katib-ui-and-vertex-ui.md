# Katib's UI and Vertex AI's UI

friend1: open-source contributions to Kubeflow were taken commercially into Google's Vertex AI;
the UI of Katib (Kubeflow's hyperparameter tuner) matched Vertex AI's UI "100%".

**Status: unverified.** I have not compared the two UIs. To verify: screenshots of Katib's UI and
of Vertex AI's tuning UI at dated versions, side by side, and the commit history of both.

**Context to check.** Katib's own paper and documentation say Katib was *inspired by* Google
Vizier, Google's internal tuning service (George et al., "A Scalable and Cloud-Native Hyperparameter
Tuning System", [arXiv:2006.02085](https://arxiv.org/abs/2006.02085); not yet read in full). So the
influence may run in both directions; the note must not claim who copied whom without evidence.
