# Cloud providers capture open source

A cloud provider can take an open-source project, run it as a paid service, and keep its own
changes and interface closed. The authors give the work; the provider sells it. This is the
closed-source move in a new place: the code is open, the service around it is not.

Cases to support it:

- [[202610122237-elasticsearch-and-aws]] (partly sourced).
- [[202610122236-katib-ui-and-vertex-ui]] (unverified).

For the book: this is an argument *for* citation and copyleft (AGPL), not against openness; see
Section 6 of the paper and [[202610122239-espionage-and-agents-at-scale]].
