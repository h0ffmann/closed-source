# Elasticsearch and AWS

friend1 named Elasticsearch against AWS as a case of a cloud provider selling an open-source
project as a service. The public record: in 2021 Elastic moved Elasticsearch and Kibana from the
Apache 2.0 licence to licences that restrict offering them as a service, and named AWS as the
reason; AWS then maintained an Apache 2.0 fork, OpenSearch. In 2024 Elastic added the AGPL as a
licence option again, and its CTO said the market had changed because AWS now invests in its fork.
